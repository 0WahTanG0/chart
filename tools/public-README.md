# График смен

Готовые файлы приложения «График смен». Исходники лежат в закрытом репозитории.

- `grafik-smen.apk` — приложение для Android. Установите его один раз, дальше оно обновляется само.
- `index.html` — последняя версия страницы. Приложение скачивает её при обновлении.
- `version.json` — номер последней версии. Приложение проверяет его при каждом запуске.
- `grafik-smen-itch-*.zip` — архив для загрузки на itch.io.

Данные (сотрудники, календари, настройки) хранятся только на устройстве и сюда не попадают.
